## ⚡ Introduction

**Snapabase** is a desktop management application designed specifically for Supabase projects. It empowers developers to securely back up, manage, and restore their Supabase databases and Edge Functions directly from their local machines. 

Built with privacy and performance in mind, Snapabase ensures that your database credentials and sensitive data never leave your device.

## ✨ Key Features

- 🔒 **Local-First Architecture:** Complete data privacy. Your credentials and backups are stored locally and never transmitted to external servers.
- 🚀 **Native Performance:** Bypasses Docker entirely. Snapabase uses native PostgreSQL binaries (`pg_dump` and `psql`) for blazing-fast database operations.
- 📦 **Edge Functions Management:** Seamlessly back up and deploy your Supabase Edge Functions using the official Supabase CLI integration.
- 🔄 **Streamlined Restores:** Avoid data conflicts with a guided, intuitive restore process for new or existing Supabase projects.
- 🖥️ **Cross-Platform:** Beautiful and responsive desktop client available for both Windows and macOS.
